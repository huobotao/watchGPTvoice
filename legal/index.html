案件基本信息

先把案情骨架填好，后续 AI 分析会基于此上下文。

对方的指控 / 事实主张

把对方起诉状里每一条独立的事实主张拆开录入。一条一条拆开是关键——后面要逐条质证。

我方事实主张

写下你认为的"真相版本"。AI 会对比双方版本找差异点。

我方已有证据

手里有什么先列出来，AI 会判断证明力 / 是否需要补强。

AI 策略分析

两种使用方式：
🟦 直连模式（推荐）— 在右上角【设置】填 API Key，下方按钮直接出结果。
🟩 免 Key 模式 — 点【复制提示词】，去 ChatGPT 或 Claude.ai 网页版粘贴（免费账号也能用）。

1. 构成要件分解

把对方每条指控拆解为法律构成要件，标出"对方必须证明哪几个事实"，你只要打掉任何一个，该指控就不成立。

2. 逐条质证思路

针对对方可能提交的每份证据，给出质证方向：真实性 / 合法性 / 关联性，以及具体追问的话术。

3. 庭审优先级排序

哪些指控是"主战场"必须打赢，哪些是次要可以让步，哪些是陷阱不要纠缠，给出 P0/P1/P2 排序。

4. 整体辩护策略大纲

综合以上输出一份庭审打法：开场陈述要点、举证顺序、反诘问设计、风险预案。

导出
