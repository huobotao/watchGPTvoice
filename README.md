# GLP-1 一键记录 · 替尔泊肽 / 司美格鲁肽

一个极简的网页工具：一键记录"打了一针 / 吃了一顿 / 称了体重"，自动算出"距上一顿多久、距上一针多久"，并把吃饭顿数 + 体重画到同一张图上，方便观察 GLP-1 类减肥药对你饮食频率与体重的影响。

不记录卡路里 — 因为很难准确。只记录**事件本身**和**时间戳**，因为：
- 吃饭顿数（频率）是稳定可记的客观指标
- 顿数随药效的变化才是这类药对食欲影响最直接的体现
- 不增加心智负担，按一下就好

## 使用

直接用浏览器打开 `index.html`（手机也可以，加到主屏幕当 PWA 用）。

- 🍽️ **吃了一顿** — 一键记录，立即写入
- 💉 **打了一针** — 选药（替尔泊肽 / 司美格鲁肽）+ 剂量，下次默认沿用上次的
- ⚖️ **称了体重** — 输入公斤数

顶部三张卡片实时显示：距上次吃饭多久、距上次打针多久、最近体重。
下方近 30 天图：橙色柱是当日顿数，绿色折线是体重，蓝色小三角是打针日。
点任意一条历史记录可删除。右上"导出 CSV"可把所有数据带走自己分析。

## 数据

所有数据存在浏览器 localStorage（key = `glp1.events.v1`），不上传任何服务器。换浏览器或清缓存会丢，记得定期导出 CSV。

事件结构：

```json
{ "id": "...", "t": 1715900000000, "type": "meal" }
{ "id": "...", "t": 1715900000000, "type": "shot",   "drug": "tirzepatide", "dose": 5 }
{ "id": "...", "t": 1715900000000, "type": "weight", "value": 78.5 }
```
